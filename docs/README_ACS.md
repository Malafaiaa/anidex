# Mapeamento das etapas acadêmicas

Este arquivo relaciona cada etapa acadêmica a uma funcionalidade principal do AniDex.

| Etapa | Funcionalidade |
| --- | --- |
| AC1 | Busca de animes e catálogo A–Z |
| AC2 | Minha Lista com status, episódio e minutagem |
| AC3 | Sistema de avaliações |
| Prova | Recuperação de senha por código enviado por e-mail |
